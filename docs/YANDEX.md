# Публикация на Яндекс Играх

## 1. Сборка

```bash
npm ci
npm run build
```

Результат — папка `dist/` (≈ 700 КБ, из них ~660 КБ JS, gzip ~175 КБ):
`index.html`, `assets/*.js`, `assets/*.css`. Внешних запросов, кроме SDK, нет.

`vite.config.js` использует `base: './'`, поэтому сборка работает и в корне
домена, и в подкаталоге статического хостинга.

## 2. Черновик в консоли разработчика

1. https://games.yandex.ru/console → «Создать игру».
2. Название: **Короны Европы** (проверить занятость; альтернатива — Crowns of Europe).
3. Категория: Стратегии. Возрастной рейтинг: 6+.
4. Ориентация: альбомная. Платформы: десктоп и мобильные.
5. Загрузить архив `dist/` в раздел «Файлы игры».
6. Заполнить карточку: иконка 512×512, обложка, скриншоты 16:9 (можно снять из игры).

## 3. SDK

`src/platform/yandex.js` подключает `https://yandex.ru/games/sdk/v2` только на
доменах Яндекс Игр (или при `?ysdk` в URL). Локально и в превью SDK не грузится,
игра полностью работоспособна.

Что уже используется:

| API | Где | Зачем |
|---|---|---|
| `YaGames.init()` | `platform.init()` | инициализация |
| `features.LoadingAPI.ready()` | после инициализации | убрать экран загрузки |
| `features.GameplayAPI.start/stop()` | вход в партию, пауза, финал | корректный учёт геймплея |
| `getPlayer().setData/getData` | автосохранение каждые 12 с | облачный прогресс |
| `adv.showFullscreenAdv()` | экран итогов | межстраничная реклама |
| `leaderboards.setLeaderboardScore` | финал партии | таблица лидеров `crowns` |
| `leaderboards.getLeaderboardEntries` | экран итогов | топ-5 на экране победы/поражения |

Таблицу лидеров `crowns` надо создать в консоли разработчика (тип — числовая,
сортировка по убыванию). Пока её нет, `setLeaderboardScore` тихо падает,
игра показывает только очки партии.

Реклама показывается не чаще одного раза за партию (на экране победы или
поражения) и не прерывает игровой процесс. Звук на время рекламы не
останавливается принудительно, потому что SDK сам управляет фокусом; при
желании можно добавить `sfx.setEnabled(false)` в колбэке `onOpen`.

## 4. Чек-лист модерации

- [ ] Игра запускается без ошибок в консоли (проверено в Chromium + WebGL 2).
- [ ] Есть экран «Как играть» и понятное управление на тач-устройствах.
- [ ] Нет внешних ссылок, чатов и запросов на сторонние домены.
- [ ] Нет ассетов и текстов, взятых из других игр (см. `docs/clean-room/`).
- [ ] Сохранения не блокируют игру, если SDK недоступен.
- [ ] Реклама не показывается во время активного геймплея.
- [ ] Указан возрастной рейтинг 6+ (война без крови и жестокости).
- [ ] Игра адаптируется к изменению размера окна и повороту экрана (проверено 844×390, 667×375, 1024×600).

## 5. Локализация

Весь текст интерфейса — русский, строки сосредоточены в `index.html`,
`src/ui/app.js` и `src/data/scenarios.js`. Для английской версии достаточно
добавить словарь и заменить литералы; структура данных уже содержит `name`
и `nameRu` для провинций.
