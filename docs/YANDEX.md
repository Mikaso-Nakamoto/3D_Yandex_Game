# Публикация на Яндекс Играх

## 1. Сборка

```bash
npm ci
npm run build
```

Результат — папка `dist/` (≈ 700 КБ, из них ~660 КБ JS, gzip ~175 КБ):
`index.html`, `assets/*.js`, `assets/*.css`. Внешних запросов, кроме SDK, нет.

`vite.config.js` использует `base: './'`, поэтому сборка работает и в корне
домена, и в подкаталоге статического хостинга.

## 2. Черновик в консоли разработчика

1. https://games.yandex.ru/console → «Создать игру».
2. Название: **Короны Европы** (проверить занятость; альтернатива — Crowns of Europe).
3. Категория: Стратегии. Возрастной рейтинг: 6+.
4. Ориентация: альбомная. Платформы: десктоп и мобильные.
5. Загрузить архив `dist/` в раздел «Файлы игры».
6. Заполнить карточку: иконка 512×512, обложка, скриншоты 16:9 (можно снять из игры).

## 3. SDK

`src/platform/yandex.js` подключает `https://yandex.ru/games/sdk/v2` только на
доменах Яндекс Игр (или при `?ysdk` в URL). Локально и в превью SDK не грузится,
игра полностью работоспособна.

Что уже используется:

| API | Где | Зачем |
|---|---|---|
| `YaGames.init()` | `platform.init()` | инициализация |
| `features.LoadingAPI.ready()` | после инициализации | убрать экран загрузки |
| `features.GameplayAPI.start/stop()` | вход в партию, пауза, финал | корректный учёт геймплея |
| `getPlayer().setData/getData` | автосохранение каждые 12 с | облачный прогресс |
| `adv.showFullscreenAdv()` | экран итогов | межстраничная реклама |
| `adv.showRewardedVideo()` | экран итогов, список приказов | «второй шанс» и ускорение приказов |
| `leaderboards.setLeaderboardScore` | финал партии | таблицы `crowns`, `crowns_stars`, `crowns_time` |
| `leaderboards.getLeaderboardEntries` | экран итогов | лидер и место игрока в двух таблицах |
| `getAchievements` / `setAchievement` | финал партии | достижения К5 |

Таблицы лидеров надо создать в консоли разработчика (все числовые, сортировка
по убыванию). Пока их нет, `setLeaderboardScore` тихо падает, и строка
лидерборда на экране итогов просто не появляется.

| Таблица | Что отправляется |
|---|---|
| `crowns` | очки партии (`Game#score().total`) |
| `crowns_stars` | сумма звёзд по всем сценариям |
| `crowns_time` | `7200 − секунды до цели`: таблицы сортируют по убыванию, поэтому «быстрее» = «больше» |

Достижения (id — ровно такие, как в консоли):

| id | Название | Когда |
|---|---|---|
| `first_win` | Первая победа | цель достигнута впервые |
| `three_stars` | Три звезды | цель, земля и слово сразу |
| `no_losses` | Без потерь | победа без единой потерянной провинции |
| `daily` | Задача дня | выполнена задача дня |

Если в консоли достижения ещё не заведены, вызов молча падает, а игра
показывает их сама на экране итогов.

### Реклама и монетизация (К6)

Три правила, и все три проверены в браузере со стабом SDK:

1. **Первые три партии — без рекламы вообще.** Счётчик `matches` растёт на
   экране итогов (урок не считается партией) и синхронизируется облаком, чтобы
   второй браузер не подарил новичку ещё три чистые партии.
2. **Межстраничная — не чаще раза в две партии.** Считается в
   `interstitialAllowed({ matches, lastAd })`, вызывается через 1,6 с после
   появления экрана итогов. Если на этом экране предлагается «второй шанс», а
   игрок его ещё не использовал, реклама не показывается: два ролика на одном
   экране — это способ научить игрока закрывать вкладку.
3. **Rewarded — только по нажатию и с честной подписью.**

| Кнопка | Где | Что даёт | Ограничение |
|---|---|---|---|
| «Второй шанс» | экран поражения | столица возвращается с 30 % армии, которую держава когда-либо имела, и 25 с передышки (ИИ не атакует) | один раз за партию; земли не возвращаются |
| «Ускорить» (в списке приказов) | приказ на кулдауне | снимает кулдаун всех трёх приказов | один раз за партию |

Если SDK нет (браузер, отладка), кнопки не рисуются вовсе: мёртвая кнопка на
экране поражения хуже, чем её отсутствие. Если реклама не загрузилась или
игрок закрыл её — ничего не тратится, партия остаётся как была, и об этом
честно пишет тост.

Звук на время рекламы не останавливается принудительно: SDK сам управляет
фокусом; при желании можно добавить `sfx.setEnabled(false)` в колбэке `onOpen`.

## 4. Чек-лист модерации

- [x] Игра запускается без ошибок в консоли (проверено в Chromium + WebGL 2;
      прогоны К5/К6 — 0 ошибок).
- [x] Есть экран «Как играть» и понятное управление на тач-устройствах (урок на
      три шага на первом запуске).
- [x] Нет внешних ссылок, чатов и запросов на сторонние домены.
- [x] Нет ассетов и текстов, взятых из других игр (см. `docs/clean-room/`).
- [x] Сохранения не блокируют игру, если SDK недоступен.
- [x] Реклама не показывается во время активного геймплея (только на экране
      итогов и по нажатию «Второй шанс» / «Ускорить»).
- [x] Первые три партии проходят без рекламы.
- [x] Указан возрастной рейтинг 6+ (война без крови и жестокости).
- [x] Игра адаптируется к изменению размера окна и повороту экрана (проверено
      844×390, 1024×560, 1024×600, 1280×720).

## 5. Локализация

Весь текст интерфейса — русский, строки сосредоточены в `index.html`,
`src/ui/app.js` и `src/data/scenarios.js`. Для английской версии достаточно
добавить словарь и заменить литералы; структура данных уже содержит `name`
и `nameRu` для провинций.
