# Crowns of Europe / Короны Европы

Браузерная стратегия завоевания в реальном времени для **Яндекс Игр**:
выбираете театр (Европа или Северная Америка), эпоху и державу,
перетаскиваете армии между соседними провинциями, развиваете земли
и захватываете все провинции театра.

Карта — 3D-экструзия на three.js, данные — Natural Earth 110m (public domain).
Ассетов, кода и текстов из игры-референса в проекте нет: процесс описан в
[`docs/clean-room/`](docs/clean-room/).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ — статика для Яндекс Игр
npm run preview  # предпросмотр сборки
npm test         # 114 тестов: карта, правила, бой, ИИ, сохранения
```

Пересобрать карту из исходных геоданных:

```bash
node tools/build-admin1.mjs     # Natural Earth 10m admin-1 -> src/data/admin1.json (нужен файл в .cache/)
npm run geo      # tools/build-map.mjs -> src/data/map.json + map-america.json
node tools/build-atlantic.mjs   # map.json + map-america.json -> map-atlantic.json
node tools/build-world.mjs      # три источника -> map-world.json
```

## Что внутри

| Путь | Назначение |
|---|---|
| `src/game/` | чистая симуляция (экономика, армии, бой, ИИ), без DOM |
| `src/render/` | three.js: экструзия провинций, камера, пикинг, подписи |
| `src/ui/` | экраны меню и партии, HUD, журнал |
| `src/data/` | сценарии (4 эпохи, 3 театра), списки провинций, сгенерированные карты |
| `src/platform/` | Yandex Games SDK: ready, сохранения, реклама |
| `tools/` | пайплайн геоданных |
| `docs/clean-room/` | спецификация, отличия от референса, журнал происхождения |
| `tests/` | node:test — карта, правила, бой, сохранения, детерминизм |

## Игровой цикл

1. Театр: Европа (Венский концерт 1815, Канун войны 1939, Мозаика 1444)
   или Северная Америка (Новый Свет 1815).
2. Держава и доктрина: Оружие / Казна / Стены.
3. Переброска войск драгом из своей провинции в соседнюю (морские маршруты для островов).
   Из одной провинции можно одновременно отправить несколько отрядов в разные стороны —
   каждый забирает свою долю оставшегося гарнизона.
4. Улучшения провинций: мануфактура, крепость, казармы (3 уровня). Гарнизон
   набирается сам: сначала до нормы, затем медленнее — сверх неё (излишек виден
   золотым «+N» и не пропадает).
5. Бой прогнозируем: в панели чужой провинции видно шанс захвата, оборону к
   прибытию и сколько войск хватит наверняка. Шанс считается по отношению сил
   и учитывает крепость, доктрину, дух и пополнение защитника в пути.
6. Приказы: мобилизация, военный налог, форсированный марш (общий кулдаун).
7. Победа только при полном контроле театра — все провинции. Поражение — потеря всех земель.

## Театры

| Театр | Провинций | Эпохи | Особенность |
|---|---|---|---|
| Европа | 43 | 1815, 1939, 1444 | плотные границы, короткие марши |
| Европа и Северная Америка | 56 | 1815, 1939, 1444, 1861 | два берега Атлантики, морские пути |
| Весь мир | 196 | 1939 | карта-цилиндр: листается без края, Сибирь достаёт до Аляски |

Театр выбирается вместе со сценарием: у каждого сценария своя карта, и игра
не запустится с чужой.

- «Новый Свет» (1815): США, Британская Северная Америка, Испанские колонии,
  Русская Америка и Гаити.
- «Дом разделённый» (1861): Союз, Конфедерация, Британия, Мексика, Гаити.

## Дух, усталость и дипломатия

| Показатель | Что делает |
|---|---|
| Боевой дух (0-100) | ±18 % к силе боя; растёт от побед, падает от потерь; ниже 25 начинается дезертирство |
| Военная усталость (0-100) | до −30 % дохода; растёт от боёв и захватов, спадает через 35 с без стычек |
| Перемирие | уставший и проигрывающий ИИ предлагает мир; принятие даёт 150 с перемирия |
| Контрудар | отбивший штурм гарнизон иногда сам идёт на провинцию, откуда пришла атака |

Мирное предложение приходит карточкой сверху: «Принять» или «Воевать» с
таймером на 45 секунд. Нарушить перемирие можно, но это стоит усталости и
делает вас aggressor'ом в глазах ИИ. Все показатели видны в HUD, в «Обстановке»
и учитываются в сохранении.

## Очки и таблица лидеров

После партии считается счёт: доля земель, захваты, отбитые атаки, бонус за
скорость и +500 за победу, минус потери провинций. На Яндекс Играх результат
уходит в таблицу лидеров `crowns` (`platform.submitScore`), и на экране итогов
показывается топ-5. Вне Яндекса всё это молча пропускается.

## Правила партии

Открываются на экране выбора державы («Правила» под доктриной) и в паузе.
В партии применяются сразу, для новой партии — при старте.

| Правило | Значения | Что делает |
|---|---|---|
| Агрессивность ИИ | Спокойная / Обычная / Жёсткая | как часто ИИ решается нападать |
| Мир до вашей войны | Вкл / Выкл | ИИ не нападает на вас, пока вы первым не атакуете (войны между ИИ идут) |
| ИИ совсем не воюет | Да / Нет | песочница: державы только развиваются и обороняются |
| Экономика ИИ | Слабая / Обычная / Сильная | доход и рекруты компьютерных держав |
| Нейтральные провинции | Слабые / Обычные / Сильные | гарнизоны ничейных земель |
| Условие победы | 40 / 50 / 65 % | доля провинций для победы |
| Старт на паузе | Да / Нет | партия начинается остановленной |

## Управление

| Действие | Мышь / клавиатура | Тач |
|---|---|---|
| Переброска войск | зажать провинцию → отпустить на соседней (можно несколько отрядов сразу в разные стороны) | то же |
| Панорама | тянуть пустую область / ПКМ / WASD | один палец |
| Зум | колесо, `+` / `-` | щипок |
| Приказы | `M` мобилизация, `T` налог, `F` марш | кнопки внизу |
| Доля в поход | `Tab` переключает 25/50/75/100 % | сегмент «В поход» |
| Обстановка | `R` | «Державы» |
| Улучшения | клик по провинции | тап |
| Пауза / скорость | `Пробел`, `1` `2` `4` | кнопки в HUD |
| Меню | `Esc` | ☰ |

## Публикация

Сборка кладётся в `dist/` и загружается в черновик Яндекс Игр. SDK
подключается только на доменах Яндекс Игр; локально игра работает без него.
Подробнее — в [`docs/YANDEX.md`](docs/YANDEX.md).
