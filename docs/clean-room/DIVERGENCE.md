# Отличия от референса

Референс: «Битва за Европу» (The Battle for Europe, DH) на Яндекс Играх.
Таблица фиксирует, что в Crowns of Europe сделано иначе. Цель — не «копия один
в один», а собственный продукт в жанре real-time conquest.

| Аспект | Референс (публичное описание) | Crowns of Europe |
|---|---|---|
| Название | «Битва за Европу» | «Crowns of Europe» / «Короны Европы» |
| Карта | Собственная нарезка, ~40+ провинций | 42 провинции (Европа) или 55 провинций на общей карте Европы и Северной Америки, из Natural Earth 110m, с отдельным Калининградом; собственная экструзия и стилизация |
| Режимы | Одна карта | Два режима: «Европа» и «Европа и Северная Америка» — отдельной американской карты нет |
| Геометрия карты | 2D-полотно | 3D-экструзия с освещением, параллаксом камеры и свободным панорамированием |
| Эпохи | Три периода, заявлены как исторические | Три собственных сценария с другим составом держав: 1815, 1939, 1444 |
| Державы | Набор стран | 11 / 21 / 11 держав в сценариях, у каждой доктрина и столица |
| Выбор в начале | Страна + эпоха | Страна + эпоха + **доктрина** (Оружие / Казна / Стены) |
| Улучшения | Фабрика, бункер | Три линии: мануфактура, крепость, казармы (по 3 уровня) |
| Временные усиления | Баффы через меню | Три **приказа** с общим кулдауном и разными эффектами |
| Бой | Н/д | Детерминированная формула с ±8 % разбросом, бонусами доктрин и крепостей |
| Дипломатия | Отсутствует | Пакты и перемирия: ИИ предлагает, игрок предлагает в ответ, обе стороны могут нарушить договор и потерять доверие; колонны, уже идущие на партнёра, при подписании поворачивают назад |
| Планирование марша | Н/д | Маршрут через свои провинции без остановок: видно всю дорогу, можно оставить гарнизон в любой провинции по пути |
| Национальные цели | Отсутствуют | **Исторический фокус**: цепочка из 2-3 амбиций с наградой за взятую провинцию (у ИИ тоже) |
| Морские маршруты | Н/д | Явные проливы и морские связи для островов |
| Победа | Захват Европы | Полный контроль над всеми провинциями + экран итогов |
| Сохранения | Н/д | Автосохранение в localStorage + Yandex player data |
| Арт | Собственный | Собственный: процедурные цвета, скруглённые подписи, «военная карта» |
| Звук | Н/д | Синтезированные WebAudio-эффекты, без внешних ассетов |
| Платформа | Яндекс Игры | Яндекс Игры + standalone-сборка, поддержка тача |
| Исходные данные | Н/д | Natural Earth (public domain), three.js |

## Сознательно НЕ копировалось

- Композиция экрана и расположение элементов оригинала.
- Цветовые схемы, иконки, шрифты, логотип.
- Названия провинций и государств оригинала.
- Тексты описаний и подсказок.
- Числовые значения баланса (взяты собственные, получены из расчёта).
- Название, разработчик, скриншоты.

## Что осталось общим (и почему это допустимо)

Жанровые идеи: карта из провинций, переброска войск между соседями, Income/Upkeep,
улучшения провинций, исторические эпохи, real-time с паузой. Эти механики
относятся к идеям и не охраняются авторским правом; охраняется конкретная
реализация, которая здесь написана с нуля.
